**SnapBack 1.0.0** — the first public release.

Return your Windows session to its fresh-start state without rebooting: SnapBack records the state
you want (a baseline, or profiles such as *Clean*, *Work*, *Gaming*), shows how far the session has
drifted and what actually uses your memory, and closes the extra applications **politely** — with a
preview, without touching system, elevated or other users' processes, and never forcing anything
without your explicit confirmation.

### Highlights
- **Return to baseline / profile** with preview and dry run; polite closing (close request,
  Ctrl+C, Restart Manager); forced termination only after a separate, time-limited confirmation;
  fail-closed protection and PID-reuse-safe actions.
- **Dashboard**: session drift, expected impact (an estimate, with RAM in use broken down and the
  cache shown separately), uptime, apps/processes, RAM in use and available.
- **Profiles** (create from the current state, rename, update, edit, default) and **rules**
  (always keep / always close / ask every time) — rules never weaken protection.
- **Memory over time** with conservative *unusual memory growth* detection (never called a leak).
- **WSL and Docker Desktop** stopped only with `wsl --shutdown` / `docker desktop stop`, after a
  warning listing running distributions/containers.
- **Notification area** icon, close-to-tray, **start with Windows** (no admin rights), automatic
  baseline after startup, rare optional notifications. Idle in the tray: ~0 CPU, ~36 MB private memory.
- Optional **Deep Memory Cleanup** (standby cache only, never automatic, UAC only for that operation).
- **English, Русский, 简体中文**, live language switching; `snapback-cli.exe` for scripting.

**SnapBack 1.0.0** — первый публичный релиз. Возвращает сеанс Windows к «чистому» состоянию без
перезагрузки: baseline и профили (Чистый, Работа, Игры), отклонение сеанса и ожидаемый эффект,
вежливое закрытие лишних приложений с предпросмотром, защита системных процессов, правила, рост
памяти, WSL/Docker их собственными командами, трей и автозапуск, необязательная глубокая очистка
памяти. Интерфейс на английском, русском и китайском. Скачайте архив для своей платформы,
распакуйте и запустите `SnapBack.exe`.

**SnapBack 1.0.0** — 首个公开版本。无需重启即可让 Windows 会话回到干净状态：基线与配置文件、会话偏移与预期效果、
带预览的礼貌关闭、系统进程保护、规则、内存增长、通过各自命令停止 WSL/Docker、托盘与开机启动，以及可选的深度内存清理。
界面支持英语、俄语和简体中文。下载对应平台的压缩包，解压后运行 `SnapBack.exe`。
