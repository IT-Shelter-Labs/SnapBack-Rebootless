## Русский

### Скачать и запустить

- Обычный компьютер с Windows: **SnapBack-1.0.1-win-x64.zip**.
- Windows на ARM: **SnapBack-1.0.1-win-arm64.zip**.
- **SHA256SUMS.txt**: контрольные суммы архивов.

Распакуйте архив и запустите `SnapBack.exe`. Устанавливать .NET отдельно не нужно.
Перед обновлением выйдите из старого SnapBack через значок в трее → **Выход**,
затем запустите EXE из новой папки. Настройки и профили сохраняются в пользовательской папке приложения.
